# kestrel-point-genai-governance-investment-banking
AI governance programme for a fictional investment bank using GenAI across 14 deal-lifecycle use cases: inventory and risk tiering, MNPI controls, risk register, control library mapped to NIST AI RMF, ISO/IEC 42001, EU AI Act, SR 11-7, MAR, FINRA and DORA, control testing and Board reporting.
